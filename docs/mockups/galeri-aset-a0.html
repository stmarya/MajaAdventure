Memuat inventaris aset…

Cara membuka galeri: jalankan server lokal dari folder proyek dengan python3 -m http.server 8080, lalu buka http://localhost:8080/docs/mockups/galeri-aset-a0.html. Aset arsip dimuat dari paket ZIP secara bertahap saat gambarnya terlihat atau saat audio dipilih. Buka lewat server lokal, bukan file://.
Kartu arsip yang byte-identik memakai pratinjau file kanonis agar hemat pemuatan, tetapi tetap menampilkan lokasi sumber arsipnya. Label “belum aktif” atau “kandidat” adalah status audit, bukan keputusan untuk menghapus.
