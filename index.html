Cara bermain dan tujuan

Capai gerbang di ujung kanan. Ambil Gobog untuk skor dan buah Maja untuk memulihkan HP. Dekati penanda obor untuk mengaktifkan checkpoint.

A/D atau ←/→: bergerak. W/↑/X/Spasi: lompat. Z: serang. S/↓ + lompat: turun dari platform kayu satu arah. Esc: jeda. M: audio.

Setelah mati, “Coba lagi” mempertahankan collectible dan skor run. “Ulang dari awal” mereset seluruh level. Highscore disimpan di browser; checkpoint tidak disimpan setelah halaman ditutup.

Target pengujian utama: web + keyboard. Kontrol sentuh masih eksperimental; gamepad dan build native belum didukung. Game Canvas ini belum sepenuhnya dapat dimainkan dengan pembaca layar.
